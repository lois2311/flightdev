## 🧭 Sobre flightdev

**flightdev** es un estudio de desarrollo de software fundado en **Manizales, Colombia**, dedicado a la creación de productos digitales, plataformas operativas y automatizaciones para negocios que buscan dar el salto definitivo hacia la digitalización.

Creemos firmemente que la tecnología de vanguardia no debe ser un lujo reservado únicamente para grandes corporaciones. Nuestro enfoque combina ingeniería de software rigurosa, diseño centrado en el usuario y modelos accesibles para resolver necesidades reales del ecosistema comercial y empresarial.

## ⚡ Producto Insignia: Vendra POS

> **vendraPOS** es nuestro primer producto funcional de gestión comercial y punto de venta.

### 🎯 El Problema que Resolvemos
Miles de pequeños comercios, tiendas y emprendimientos siguen gestionando sus ventas en cuadernos o tablas desorganizadas de Excel por dos barreras principales:
1. **Costos excesivos:** Los sistemas de punto de venta convencionales imponen suscripciones elevadas.
2. **Facturación electrónica penalizante:** Las comisiones por emisión electrónica devoran el margen de ganancia de los pequeños negocios.

### 💡 La Solución Vendra
- **Control Centralizado de Ventas:** Registro ultra-rápido en caja (diseñado para operación por teclado `F1`, `F3`, `F4`), gestión de tickets y arqueos.
- **Facturación Electrónica Accesible:** Emisión de comprobantes y validación fiscal transparente que protege el margen y la rentabilidad del comerciante.
- **Segmento Low-Cost Competitivo:** Un sistema ágil, moderno e intuitivo que democratiza la tecnología comercial para micro y pequeñas empresas.
- **Simulador Interactivo:** Esta plataforma incluye un demo interactivo que replica el flujo completo de caja en tiempo real.

## 🚀 Puesta en Marcha Local

Para clonar e inspeccionar este proyecto en tu entorno local:

```bash
# 1. Clonar el repositorio
git clone https://github.com/lois2311/flightdev.git

# 2. Entrar a la carpeta del proyecto
cd flightdev

# 3. Instalar dependencias
npm install

# 4. Iniciar servidor de desarrollo local
npm run dev
```

La aplicación estará disponible de inmediato en `http://localhost:5173`.

### 📦 Construcción para Producción

```bash
# Compilar TypeScript y empaquetar para producción
npm run build

# Previsualizar el build generado
npm run preview
```
